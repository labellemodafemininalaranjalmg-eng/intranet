⚙️ Funções e Parâmetros

Organização e reutilização do código

O que são funções?

Funções são blocos de código nomeados que executam uma tarefa específica. Permitem reutilizar código sem repetição, facilitando a manutenção e leitura do programa.

Parâmetros e argumentos

Parâmetros são as variáveis definidas na função. Argumentos são os valores passados ao chamá-la. Uma função pode ter parâmetros opcionais com valores padrão.

# Parâmetro com valor padrão def saudar(nome, turno="dia"): return f"Bom {turno}, {nome}!" print(saudar("Patrícia")) # Bom dia, Patrícia! print(saudar("Carlos", "noite")) # Bom noite, Carlos!

🔭 Escopo de Variáveis

Onde uma variável existe no código

Escopo local

Variáveis criadas dentro de uma função só existem dentro dela. Ao sair da função, são destruídas.

Escopo global

Variáveis criadas fora de funções são globais — existem em todo o programa. Use com cautela para evitar conflitos.

total = 0 # variável global def somar(a, b): resultado = a + b # variável local return resultado total = somar(5, 3) print(total) # 8 # print(resultado) ← ERRO! não existe aqui

🔄 Recursividade

Funções que chamam a si mesmas

O que é recursividade?

Uma função recursiva é aquela que chama a si mesma para resolver versões menores do mesmo problema. Sempre precisa de um caso base para parar — sem ele, entra em loop infinito.

Caso base e caso recursivo

O caso base é a condição que encerra a recursão. O caso recursivo é a chamada da própria função com um valor menor.

def fatorial(n): if n == 0: # caso base return 1 return n * fatorial(n - 1) # recursão print(fatorial(5)) # 120 # 5 × 4 × 3 × 2 × 1 = 120

📁 Manipulação de Arquivos

Leitura e escrita em arquivos

Por que manipular arquivos?

Dados em variáveis desaparecem quando o programa fecha. Arquivos permitem persistência — guardar informações entre execuções. É exatamente o que fazemos neste projeto com os arquivos JSON.

Modos de abertura

"r" — leitura  |  "w" — escrita (apaga o existente)  |  "a" — adiciona ao final

# Escrevendo em arquivo with open("dados.txt", "w", encoding="utf-8") as f: f.write("Olá, arquivo!") # Lendo o arquivo with open("dados.txt", "r", encoding="utf-8") as f: conteudo = f.read() print(conteudo)

📦 Módulos e Bibliotecas

Reutilizando código entre arquivos

O que é um módulo?

Um módulo é um arquivo Python que contém funções, variáveis e classes que podem ser importados por outros arquivos. Este projeto usa módulos: database.py, recomendacoes.py e routes.py são módulos que o app.py importa.

Bibliotecas externas

São módulos criados por terceiros e instalados via pip. O Flask, usado neste projeto, é uma biblioteca externa.

# Importando módulo inteiro import json # Importando função específica from datetime import date # Importando do nosso próprio módulo from database import get_noticias

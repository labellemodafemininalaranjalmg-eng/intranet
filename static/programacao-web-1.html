📡 Protocolo HTTP e Ciclo Web

Ciclo de Requisição/Resposta

O que é protocolo HTTP?

HTTP (Hypertext Transfer Protocol) é o protocolo padrão para comunicação entre navegadores e servidores na web. Ele define como os mensagens são formatadas e transmitidas.

Status Codes comuns

200 OK - A requisição foi bem-sucedida.
404 Not Found - O recurso solicitado não foi encontrado.
500 Internal Server Error - Erro interno do servidor.

# Simulação de log de requisições no Flask 127.0.0.1 - - ["GET /api/disciplinas HTTP/1.1"] 200 - 127.0.0.1 - - ["POST /api/anotacoes HTTP/1.1"] 201 -

Rotas e Métodos HTTP

Definição e uso de rotas e métodos

Mapeamento de rotas

As rotas associam um endereço de URL a uma função específica em Python dentro do Flask, determinando qual lógica deve responder àquele clique do usuário. Rotas são os caminhos que um servidor usa para identificar e responder a solicitações de clientes. Cada rota está associada a um método HTTP específico.

Diferença de GET e POST

O método GET solicita a leitura e exibição de dados (visíveis na URL). O método POST envia dados complexos e estruturados dentro do corpo oculto da requisição (como formulários de login e dados de cadastro).

🎨 Motores de Templates

Renderização dinâmica com Jinja2

O que são Motores de Templates?

Os motores de templates são ferramentas que permitem criar documentos HTML com conteúdo dinâmico, substituindo placeholders por valores reais durante a execução do programa. O Jinja2 é um dos motores de template mais populares para Python.

Sintaxe básica do Jinja2

Utilizamos chaves duplas {{ }} para exibir variáveis dinâmicas do Python e tags de porcentagem {% %} para criar loops de repetição e verificações condicionais.

<!-- Estrutura dinâmica no Jinja2 --> <ul> {% for d in disciplinas %} <li>{{ d.nome }}</li> {% endfor %} </ul>

📁 Manipulação de Formulários

Envio e recepção de dados de usuários

Capturando entradas

Para coletar e manipular os dados enviados pelos inputs do usuário na interface, o Flask utiliza o objeto global request.form mapeado pelos métodos POST.

Leitura de chaves

Cada campo input do HTML deve possuir o atributo name configurado, servindo como a chave identificadora para o Python extrair a informação enviada.

from flask import request @app.route('/enviar', methods=['POST']) def enviar(): nome = request.form['nome'] email = request.form['email'] print(f"Nome: {nome}, Email: {email}") return "Dados recebidos!"

🍪 Gerenciamento de Estado

Sessões, cookies e autenticação

O conceito de Stateless

O protocolo HTTP não guarda memória de estados anteriores por si só. Para manter o usuário autenticado na Intranet sem precisar pedir a senha a cada clique, recorremos ao controle de sessões.

Sessions e segurança

O recurso session do Flask cria um cookie criptografado no navegador do cliente que armazena de forma segura a identidade ativa do usuário logado.

from flask import session # Salvando sessão ativa session["usuario_logado"] = "admin"# Importando função específica # Removendo na saída (logout) session.pop("usuario_logado", None)

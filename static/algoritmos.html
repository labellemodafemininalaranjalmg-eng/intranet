📦 Variáveis e Tipos de Dados

Como o Python armazena informações

O que é uma variável?

Uma variável é um espaço nomeado na memória do computador que armazena um valor. Em Python, não é necessário declarar o tipo — ele é inferido automaticamente.

Tipos principais

int — números inteiros (ex: 10, -3)
float — números decimais (ex: 3.14)
str — texto (ex: "Olá")
bool — verdadeiro ou falso (True / False)

# Exemplos de variáveis nome = "Patrícia" idade = 20 altura = 1.68 ativo = True print(f"Olá, {nome}! Idade: {idade}")

🔀 Estruturas Condicionais

Tomada de decisão no código

if / elif / else

Permitem que o programa execute blocos de código diferentes dependendo de uma condição. A indentação (recuo) define quais linhas pertencem a cada bloco.

Operadores de comparação

== igual a  |  != diferente  |  > maior  |  < menor  |  and e  |  or ou

nota = 7.5 if nota >= 7: print("Aprovado") elif nota >= 5: print("Recuperação") else: print("Reprovado")

🔁 Laços de Repetição

Executar código múltiplas vezes

for — quantidade definida

Usado quando sabemos quantas vezes repetir, ou quando queremos percorrer uma lista ou sequência.

while — condição

Usado quando a repetição depende de uma condição que muda durante a execução.

# for percorre uma lista frutas = ["maçã", "uva", "pera"] for fruta in frutas: print(fruta) # while com condição contador = 0 while contador < 3: print(contador) contador += 1

⚙️ Funções

Reutilização e organização do código

O que é uma função?

Uma função é um bloco de código nomeado que executa uma tarefa específica. Pode receber dados (parâmetros) e devolver um resultado (return). Evita repetição de código.

Parâmetros e retorno

Parâmetros são as entradas da função. O return define o valor que a função devolve ao código que a chamou.

def calcular_media(notas): soma = sum(notas) return soma / len(notas) minhas_notas = [8, 7, 9, 6] media = calcular_media(minhas_notas) print(f"Média: {media}")

📋 Listas e Conjuntos

Agrupamento de dados

Listas (list)

Coleção ordenada e mutável de elementos. Permite duplicatas. Acessada por índice (começa em 0).

Conjuntos (set)

Coleção não ordenada e sem duplicatas. Muito eficiente para operações como interseção (&) e união (|) — usadas no algoritmo de recomendação deste projeto!

# Lista nomes = ["Ana", "Bruno", "Ana"] # Conjunto — remove duplicatas interesses = {"Gestão", "TI"} tags = {"TI", "Logística"} # Interseção — usado no projeto! comuns = interesses & tags print(comuns) # {'TI'}
